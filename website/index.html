Lesion a population, measure the effect — inducing dyslexia

process(StateChange) ablates a unit population, the benchmark re-scores by generation, and reset() restores bit-for-bit. Honarmand et al.'s selective dyslexia reproduces at 32B: a word-form lesion drives reading below the dyslexia threshold while a same-size random lesion doesn't — and the effect emerges with model scale.

Inducing dyslexia — selectivity emerges with scale

Which neurons, across which layers

A CompositeSelector gathers a functional population spanning depth into one region. The population is defined by a functional localizer — so first, the stimuli that identify it.

Composite selection

Standard mapping records one region from one layer; 'all' records every region in one pass; a CompositeSelector pools the localized units across layers into one region.

Nulls, everywhere

No result is trusted without a matched null running through the same pipeline. If the real score doesn't clear the floor, the signal is a pipeline artifact — not the model.

What we do not claim (yet)

Honesty is the product. The same rigor that validates a result has to name where a result is contingent, under-controlled, or only proves plumbing. These are ours.
