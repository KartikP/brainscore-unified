Linux-built wheels; no editable installs. `pip check` passed. Docker build and
pip download caches were disabled. Tests had no network, AWS credentials or
result cache; verified model weights and dataset files were staged explicitly.

about 61 GiB RAM, two compute threads. This is neither native Ubuntu-host nor
GPU qualification. The worker was stopped after the batch.
