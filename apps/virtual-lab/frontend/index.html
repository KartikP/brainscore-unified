Participant

Its declarations determine which inputs, responses and recording sites are available. Loading a model does not run the protocol.

Stimuli

One row is one trial. Keep stimulus factors, such as noise or word length, as columns in the table. Fitting examples are supplied separately, with the task.

Task and response

The task says what the participant does with each stimulus. What to record is a separate part of the rig.

Fitting stimuli and readout policy

For a readout, supply a separate CSV with input columns and a label column. Media paths refer to files uploaded to this workspace. Test labels are not needed to collect responses.

The instruction comes first, then these stimulus parts, then the response directive. Specify the order when a trial has multiple parts.

Recordings

Record answers, neural activity, or both. These measurements come from one presentation of each stimulus.

Session: conditions and repetitions

Conditions name states of the participant, such as intact or lesioned. Stimulus factors belong in the stimulus table. Each repetition starts and ends with a reset.
