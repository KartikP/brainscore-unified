# Induced dyslexia

The benchmarks `Yeatman2021-induced_dyslexia-image` and `Yeatman2021-induced_dyslexia-text` switch off the word-selective units of a subject and measure the loss in lexical-decision accuracy. A random lesion of the same size is the control. The class is in `benchmark.py`.

The scripts and result files of the published run are kept outside the package.
